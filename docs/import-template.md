# 通讯录导入 CSV 模板

成员导入只支持标准 CSV 模板，不兼容旧 Excel 文件。真实通讯录包含个人敏感信息，不应提交到 Git；请只在本地或受控环境中处理。

示例模板：[sample-data/members-template.csv](../sample-data/members-template.csv)

## 标准表头

CSV 第一行建议使用以下中文表头，字段顺序建议保持一致：

```csv
精灵名,期数,姓名,手机号,微信号,邮箱,省份,城市,所在公司及现任职务,你目前主要关注或从事的领域,当前状态,用一句话介绍现在的自己,角色,通讯录授权
```

后端也接受英文别名表头，例如 `spirit_name`、`phone`、`directory_visibility`，但给秘书处使用时优先推荐中文模板。

## 字段说明

| 字段 | 含义 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `精灵名` | 精灵名 | 必填 | 校友在创见体系中的常用名。 |
| `期数` | 期数 | 选填 | 只填写数字，例如 `1`、`12`；不确定时填写 `不知道`。 |
| `姓名` | 真实姓名 | 选填 | 用于管理员核验，不公开展示给未授权对象。 |
| `手机号` | 手机号 | 必填 | 成员唯一识别字段之一，同一文件内不要重复。 |
| `微信号` | 微信号 | 选填 | 用于秘书处联系。 |
| `邮箱` | 邮箱 | 选填 | 用于备用联系。 |
| `省份` | 省份 | 选填 | 当前所在省份或地区。 |
| `城市` | 城市 | 选填 | 当前所在城市。 |
| `所在公司及现任职务` | 公司/身份/职位 | 选填 | 可写公司、项目、身份或职位摘要。 |
| `你目前主要关注或从事的领域` | 关注领域 | 选填 | 多个领域建议用英文分号 `;` 分隔。 |
| `当前状态` | 当前状态 | 选填 | 如 `在读学生`、`职场工作`、`创业中`、`自由职业`、`转型/探索阶段`、`其他`。 |
| `用一句话介绍现在的自己` | 一句话介绍 | 选填 | 用于通讯录和活动连接参考。 |
| `角色` | 成员角色 | 选填 | 空值默认按 `校友` 导入。 |
| `通讯录授权` | 通讯录可见范围 | 选填 | 建议使用 `internal` 或 `alumni`，也可填写中文授权说明。 |

## 必填项

- `spirit_name`
- `phone`

如果缺少必填字段，导入应被拒绝或该行应被标记为错误。导入前请先在表格工具中筛选空值。

## 导入规则

- 文件格式必须是 UTF-8 CSV，第一行是标准表头。
- 不支持 `.xlsx`、`.xls` 或旧版 Excel 模板。
- 一行代表一位成员。
- `期数` 只接受数字或 `不知道`，导入时旧格式 `第12期` 会被标准化为 `12`。
- `phone` 在成员表中具有唯一约束，同一手机号不要重复导入。
- 字段值中如果包含英文逗号、换行或双引号，必须按 CSV 规则用双引号包裹，并把内部双引号写成两个双引号。
- 空白选填字段可以留空，但不要删除列。
- 导入前先用虚构模板跑通本地流程，再处理真实通讯录。
- 真实通讯录、导出结果和错误明细都属于敏感数据，不要提交到 Git。

## 常见错误

| 错误 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 表头不匹配 | 列名拼写错误、使用中文列名、缺列或多列 | 复制标准表头重新整理 CSV。 |
| 缺少必填项 | `spirit_name` 或 `phone` 为空 | 补齐后重新导入。 |
| 手机号重复 | 同一 CSV 内重复，或数据库中已有该手机号 | 去重后再导入；如需更新已有成员，按系统的更新流程处理。 |
| Excel 文件无法导入 | 上传了 `.xlsx` 或 `.xls` | 从表格工具另存为 UTF-8 CSV。 |
| 中文乱码 | 文件不是 UTF-8 编码 | 重新导出 UTF-8 CSV。 |
| 列错位 | 字段里有英文逗号但没有用双引号包裹 | 按 CSV 规则转义该字段。 |
| 误提交真实名单 | 本地 Git 暂存了敏感文件 | 立即取消暂存并删除仓库中的敏感文件；如已推送，按密钥和隐私数据泄露流程处理。 |
